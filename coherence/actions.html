Actions kept with a person

These are the actions the stack keeps with the maintainer. Each row lists every mechanism that holds some part of the action, hardest to get past first, and says which part.

The holds whose instances this table lists: Deny rules and dry runs (An unattended session does something irreversible); A push tool that cannot (An unattended session does something irreversible)

A written rule and nothing else holds 3 of the 9.

  • Tool refuses The tool an agent uses will not do it.
  • Permission rule The agent harness denies the command, matched by its prefix.
  • Dry run by default The command changes nothing until it is given an explicit flag.
  • Written rule An instruction the agent is expected to follow.
