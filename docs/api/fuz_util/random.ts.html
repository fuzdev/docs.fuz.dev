random.ts

Random helpers that accept an optional random parameter, defaulting to Math.random. Pass a seeded PRNG for reproducible results:

  • create_random_xoshiro — fast, high-quality numeric seeding (recommended)
  • create_random_alea — supports string and variadic seeds
