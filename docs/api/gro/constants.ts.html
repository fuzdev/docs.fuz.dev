VITE_CONFIG_FILENAMES
#

constants.ts view source

string[] import {VITE_CONFIG_FILENAMES} from '@fuzdev/gro/constants.js';

Every filename Vite picks up as its config, in Vite's own precedence order. Which one wins is Vite's call, so Gro treats them as a set rather than privileging one extension - it detects a Vite config with all of them, and formats all of them.
