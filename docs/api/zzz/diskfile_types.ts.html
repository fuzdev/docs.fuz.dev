"change" | "add" | "touch" | "delete"

type "change" | "add" | "touch" | "delete"

import {DiskfileChangeType} from '@fuzdev/zzz/diskfile_types.js';

What happened to a file the backend indexes:

  • add — it's newly indexed
  • change — its contents differ
  • touch — its metadata changed and the contents the backend holds for it didn't (a touch, a rewrite of the same bytes), so they aren't sent again. The backend holds no contents for a file it didn't load (contents: null), so every change to such a file is a touch
  • delete — it's gone
