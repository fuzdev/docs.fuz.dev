markdown_source_map.ts

Mapping a rendered markdown preview back to its source, for the markdown view: which preview block holds the editor's caret, where a click in the preview lands in the source, and the blocks scroll sync anchors on and the outline measures (to_markdown_leaf_blocks). Built on the offsets mdz puts on what it renders (Mdz's source_offsets): data-mdz-start and data-mdz-end, UTF-16 indices into the parsed string, end exclusive.

The offsets index the string mdz parsed, and the editor's caret indexes the textarea's value, which reads every line break as \n — so the view parses to_textarea_value of its source, and the two agree.

to_markdown_leaf_blocks
#

markdown_source_map.ts view source

(blocks: readonly MarkdownBlock[]): MarkdownBlock[] import {to_markdown_leaf_blocks} from '@fuzdev/zzz/markdown_source_map.js';

The leaves of blocks: each block that holds no other, table cells aside — a row's cells sit side by side, so their tops and bottoms zigzag in y, and the row is the leaf instead. Leaves never nest or share a line, so they run in source order down the preview, their tops and bottoms each non-decreasing.
