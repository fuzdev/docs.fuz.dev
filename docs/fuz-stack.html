fuz-stack #

Overview
#

Coding conventions and patterns for the @fuzdev TypeScript, Svelte 5, and Rust ecosystem, written so an agent can learn a rule once and apply it in every repo.

The fuz-stack skill is the full text: shared rules, a TypeScript and Svelte part, and a Rust part. This page only points at it.

This content is AI-generated and mostly poorly reviewed. Not all patterns described here are endorsed, and some may be out of date or incorrect.
