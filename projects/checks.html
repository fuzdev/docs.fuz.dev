How each repo is checked

Every repo of the stack with its check command, what its own docs say of that command, and what its CI runs. Each command and comment is the repo's own text, read on 2026-11-21. This page is computed and makes no claim of its own: which command is a repo's gate is said, where it is said, on the gates page.

Every file is read at the repo's main branch as the checkout last fetched it, so nothing uncommitted or unpushed is here.

Check commands

A line is quoted when it sits in a code block of the repo's CLAUDE.md, has a # comment after the command, and either is the command gro check or npm run check, or has a comment that says to run it before committing. A repo that describes its check command in a sentence or a list, or in another file, has no line here.
