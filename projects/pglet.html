Gates

  • Types, tests, lints and format (every change): Type errors, regressions, lint errors and style drift. Where: The repos whose check script runs gro's check, with lints where the repo has a lint config. pglet's check script reaches it through a script of its own, for its TypeScript.
  • Drift in generated files (every change): A generated file that no longer matches its source. Where: The repos whose check script runs gro's check, and pglet's TypeScript the same way.
  • Release audit (every change): A forbidden crate or a test-only feature in a release build, a broken layering rule, and a copied lint table that has drifted. Where: fuz, fuz_forge and zap. pglet runs an audit of its own, for its test-only crate alone.
  • Pinned pass counts (every change): Conformance coverage that quietly shrinks or shifts. Where: pglet, and tsv's fixture validation.
  • Size limits in the gate set (every change): A WebAssembly build that has grown. Where: pglet.
  • pglet's CI leaves out the WebAssembly and concurrency suites of its gate set
